Timescale Continuous Aggregates

        
How TigerData Powers Spottr

        

          Every push-up, squat, and Apple Watch heart-rate scalar is partitioned into 1-day chunks inside TigerData. Instead of querying millions of individual PPG samples, pre-aggregated views compute daily rollups with sub-millisecond query latency.
        

        
          View Detailed Analytics & Progress Graphs →
        
      

      

        
-- Continuous Aggregate on TigerData
CREATE MATERIALIZED VIEW spottr_gateway.daily_rollups
WITH (timescaledb.continuous) AS
SELECT
  installation_id,
  time_bucket('1 day', measured_at) AS day,
  avg(value) FILTER (WHERE kind = 'heartRate') AS avg_hr,
  max(value) FILTER (WHERE kind = 'heartRate') AS max_hr,
  count(*) AS sample_count
FROM spottr_gateway.scalar_sample
GROUP BY 1, 2;
